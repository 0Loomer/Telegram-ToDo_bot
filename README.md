# Task Manager Bot

**Try the bot:** [@ToODO1O_bot] (https://t.me/ToODO1O_bot)

A Telegram bot for managing personal tasks.

## Features
- Add, edit, delete tasks
- Mark tasks as done or undone
- Switch between English and Persian languages
- Inline keyboard for easy interaction
- Persistent storage (JSON file)

## Usage
Commands:  
/start – start the bot  
/addtask – add a new task  
/tasks – show your task list  
/language – change language  
/cancel – cancel current action
